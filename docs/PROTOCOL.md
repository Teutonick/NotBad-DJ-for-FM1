# Карта управления и протокол

| Орган FM-1 | Действие |
| --- | --- |
| OCT− / OCT+ | Активная дека A / B |
| SEL | Загрузить выделенный трек в активную деку |
| PRESETS / SELECT | Перемещение по текущей библиотеке или плейлисту |
| ALGORITHM | Crossfader |
| KNOB 1–4 | Громкость, LOW, MID, HIGH |
| KNOB 1–4, второй слой | Filter, Tempo, Cue Mix, Echo Amount |
| KEY 13 / 14 / 15 | Удержание Shift / фиксация второго слоя / Echo |
| KEY 01–12 / 16–27 | Play, Cue, Sync, PFL, Nudge−, Nudge+, Loop, Half, Double, Hot 1, Hot 2, Hot 3 |
| MASTER | Локальный уровень FM-1, подлежит проверке на устройстве |

Клавиши идут по высоте. Нажатие и отпускание передаются Note On/Off на канале 1, ноты 53–79. Кнопки OCT−, OCT+ и SEL передают Note On 85–87. Энкодеры SELECT, ALGORITHM, PRESET, K1–K4 передают CC 16–22. Значения 1–63 представляют положительное число детентов, 65–127 представляют отрицательное число в дополнительном коде по модулю 128. Ускорение выполняет приложение.

SysEx Browser → FM-1 имеет формат `F0 7D 46 44 01 type seq … check F7`. Все внутренние байты семибитные. Сумма от 7D до check кратна 128. Тип 0 без полезной нагрузки сбрасывает номер последовательности. Устройство отвечает типом 2 с тремя байтами версии прошивки. Тип 1 передаёт один атомарный снимок размером 113 байт. Три общих байта представляют Crossfader, активную деку и слой. Далее два блока по 55 байт, A затем B.

| Смещение в блоке | Данные |
| --- | --- |
| 0 | Флаги PLAY, SYNC, PFL, Echo |
| 1–2 | BPM × 10, младшие семь бит первыми |
| 3–4 | Нормированные позиция и фаза |
| 5–10 | Громкость, LOW, MID, HIGH, фильтр, Echo Amount |
| 11–30 | Название ASCII, дополненное пробелами |
| 31–54 | 24 максимума огибающей трека |

Снимок обновляется каждые 125 мс и после MIDI-события. Устройство принимает последовательности в переднем полукруге номера по модулю 128, отвергает повторы и неверные контрольные суммы. Через 1,5 секунды без снимка или при потере USB состояние сбрасывается, звук USB заглушается.

Панель Hardware diagnostics сохраняет пользовательскую карту MIDI-нот в виде JSON. Например, `{"53":68,"68":53}` меняет местами Play/Pause A и B.
