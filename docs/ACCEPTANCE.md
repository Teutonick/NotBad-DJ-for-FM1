# Проверки FM-1 DJ 0.1.0

Среда локальной проверки: macOS 27.2.1 (26B131), Chrome 157.0.8103.79, Node 24.22.3. Пакет FM-1 DJ имеет идентификатор FM-1_82000100. Проверки Chrome запускались на production-файлах под путём /fm1-dj/ через локальный HTTP и с тихим аудиовыходом Web Audio.

| Тест ТЗ | Результат |
| --- | --- |
| 1. Запуск | Локальная production-сборка запускается в Chrome. Публичный запуск проверяется отдельно. |
| 2. Подключение | Host-симулятор подтвердил Note On/Off, относительный MIDI CC, обмен SysEx и отрисовку дисплея. Физический FM-1 не обнаружен. |
| 3. Библиотека | Chrome проверил импорт WAV и определение BPM. Набор из десяти пользовательских композиций, MP3 и FLAC подлежат проверке. |
| 4. DJ-микс | Chrome подтвердил транспорт и выравнивание BPM. Граф и алгоритм фазы покрыты тестами. Полный микс с FM-1 не проверен. |
| 5. Независимые выходы | Тест графа подтвердил отсутствие пути PFL → Master, а тест выбора выхода отвергает совпадающие устройства. Физический тест двух выходов и задержки не выполнен. |
| 6. 60 минут | Требуется физический прогон. |
| 7. Восстановление | Симулятор подтвердил выключение USB Audio по тайм-ауту, отключение и восстановление после нового SysEx. Требуется отдельный тест с реальным USB. |
| 8. Качество переходов | Тесты подтвердили управление коэффициентами Equal Power и плавную автоматизацию параметров. Требуется прослушивание. |
| 9. GitHub Pages | Production-сборка выпущена Vite и тестируется в Chrome. Статус публичной публикации проверяется отдельно. |
| 10. Установка прошивки | JieLi собрал .fwsc. SHA-256 проверен. Физическая установка и возврат штатной прошивки не выполнялись. |

При физической приёмке сначала проверьте маршрутизацию A/B и задержку на двух выходах. Затем проведите переход с FM-1, проверьте отключение кабеля и завершите 60-минутным прогоном.
