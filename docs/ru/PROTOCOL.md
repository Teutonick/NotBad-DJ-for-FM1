# Карта управления и протокол

[English](../PROTOCOL.md)

## FM‑1 DJ 0.1.1

`OCT−` и `OCT+` выбирают A и B. Команды панели действуют на активную деку. Кнопки `→ A` и `→ B` на странице загружают трек в указанную деку и делают её активной.

| Кнопка | Действие | MIDI |
| --- | --- | --- |
| OCT− / OCT+ | Активная дека A / B | 85 / 86 |
| SEL | Загрузить выделенный в библиотеке трек | 87 |
| PLAY | Воспроизведение / пауза | 88 |
| HOME | Остановить и вернуться к Cue | 89 |
| FX | Включить или выключить Echo | 90 |
| EDIT | Удерживать для второго слоя ручек | 91 |
| GLO | Sync при доступной синхронизации | 92 |
| ENV | PFL, включить или выключить деку в наушниках | 93 |
| ARP | Включить петлю на 4 доли или выключить текущую | 94 |
| LFO / SEQ | Уменьшить вдвое / удвоить длину петли | 95 / 96 |
| SAVE | Сохранить текущую петлю | 97 |
| REC / EDIT + REC | Отметить начало / конец ручной петли | 98 |

Пять крайних левых клавиш с учётом чёрных — F3, F♯3, G3, G♯3 и A3. Первые две временно меняют темп во время удержания. Следующие три ставят или вызывают Hot Cue 1–3. Они передают ноты 99–103. Остальные 22 клавиши свободны. REC при включении контроллера остаётся командой режима восстановления.

| Поворот | Действие | С удержанием EDIT |
| --- | --- | --- |
| SELECT / PRESETS | Листать треки текущей библиотеки или плейлиста | То же |
| ALGORITHM | Кроссфейдер | То же |
| KNOB 1 | Громкость деки | Фильтр |
| KNOB 2 | Низкие частоты | Темп |
| KNOB 3 | Средние частоты | Баланс Cue / Master в наушниках |
| KNOB 4 | Высокие частоты | Интенсивность Echo |
| MASTER | Локальный уровень FM‑1 | То же |

### Совместимость с 0.1.0

Веб-приложение продолжает принимать старые команды. В 0.1.0 нижние 12 клавиш управляли A, верхние 12 — B, три средние — SHIFT, фиксируемым вторым слоем и Echo. Новый вариант панели требует прошивку 0.1.1 и обновлённое веб-приложение.

Энкодеры SELECT, ALGORITHM, PRESET, K1–K4 передают CC 16–22 на канале 1. Значения 1–63 представляют положительное число детентов, 65–127 — отрицательное число в дополнительном коде по модулю 128. Ускорение выполняет приложение.

SysEx Browser → FM-1 имеет формат `F0 7D 46 44 01 type seq … check F7`. Все внутренние байты семибитные. Сумма от 7D до check кратна 128. Тип 0 без полезной нагрузки сбрасывает номер последовательности. Устройство отвечает типом 2 с тремя байтами версии прошивки. Тип 1 передаёт один атомарный снимок размером 113 байт. Три общих байта представляют Crossfader, активную деку и слой. Далее два блока по 55 байт, A затем B.

| Смещение в блоке | Данные |
| --- | --- |
| 0 | Флаги PLAY, SYNC, PFL, Echo |
| 1–2 | BPM × 10, младшие семь бит первыми |
| 3–4 | Нормированные позиция и фаза |
| 5–10 | Громкость, LOW, MID, HIGH, фильтр, Echo Amount |
| 11–30 | Название ASCII, дополненное пробелами |
| 31–54 | 24 максимума огибающей трека |

Браузер ждёт корректный ответ типа 2 на выбранном MIDI-входе, прежде чем отправить первый снимок и принимать команды с панели. При смене пары портов и переподключении выполняется новый обмен. Снимок обновляется каждые 125 мс и после MIDI-события. Устройство принимает последовательности в переднем полукруге номера по модулю 128, отвергает повторы и неверные контрольные суммы. Через 1,5 секунды без снимка или при потере USB состояние сбрасывается, звук USB заглушается.

Панель Hardware diagnostics сохраняет пользовательскую карту MIDI-нот 53–87 в JSON. В 0.1.0, например, `{"53":68,"68":53}` меняет местами Play/Pause A и B. Команды панели и редкие команды 0.1.1 на нотах 88–103 имеют фиксированные назначения.
