# Сторонние компоненты

Модули `fm1ota.js`, `fm1pkg.js` и `fm1ports.js` в [src/fm1/updater](../src/fm1/updater) взяты без изменений из [fm1-base, b0c384b](https://github.com/charlesvestal/fm1-base/tree/b0c384b21b095fb4f940025ce6ce7348625b4dda/web) и используются для проверки пакета и установки через Web MIDI. Их исходники и уведомления об авторских правах сохранены в репозитории. Текст лицензии [MPL-2.0](../firmware/licenses/MPL-2.0.txt). Интерфейс вкладки вдохновлён [установщиком Felucca](https://hugelton.github.io/Felucca/webapp/installer/).

- **Mini DJ**, MIT, [bc690db](https://github.com/Wincha/mini-dj/tree/bc690db1450c24c4a1c9ac7522ccc5323d22d0d1). Основа веб-приложения. Переиспользованы `src/audio/{engine,beatGrid,loops,levelMeter,analyzeTrack,metadata}.js`, `src/hooks`, `src/lib/{cuePoints,trackStore}.js` и компоненты React. Граф дополнен вторым контекстом, фильтром с плавным переходом, Echo и Equal Power. Протокол MIDI, диагностика и плейлисты добавлены в FM-1 DJ. Лицензия MIT сохранена в корне.
- **fm1-base**, MPL-2.0, [b0c384b](https://github.com/charlesvestal/fm1-base/tree/b0c384b21b095fb4f940025ce6ce7348625b4dda), с **felucca-bsp**, [7b77bfb](https://github.com/hugelton/felucca-bsp/tree/7b77bfbce8e0d185461a79d164c893551492ded1). Каталог приложения следует контракту `template/app.h`. Аппаратный слой собирается из закреплённых исходников, включая составной USB, графику, обработку панели и упаковку. Исходники прошивки имеют MPL-2.0. См. также перечень шрифтов и файлов SDK в [LICENSING.md fm1-base](https://github.com/charlesvestal/fm1-base/blob/b0c384b21b095fb4f940025ce6ce7348625b4dda/LICENSING.md).
- **DJKado**, **microdecks** и **CTL-1** использованы для сравнения архитектур. Код из этих репозиториев не включён. [DJKado](https://github.com/koneb71/djkado) · [microdecks](https://github.com/strubix/microdecks) · [CTL-1](https://github.com/charlesvestal/fm1-ctl)
- **RemoteFM1** и **VIBE DJ**, GPL-3.0, использованы как справочники по составному USB и интерфейсу. Код из них не включён. [RemoteFM1](https://github.com/Quixotic7/RemoteFM1) · [VIBE DJ](https://github.com/zvenson/vibe-dj)
